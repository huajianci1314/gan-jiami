# 淦！加密

本地音乐解锁工具，把各平台的加密音频还原为可播放的普通格式。解密全程在本机完成，零第三方依赖，不上传任何文件。

## 支持格式

| 扩展名 | 平台 | 密钥来源 | 说明 |
| --- | --- | --- | --- |
| `.ncm` | 网易云音乐 | 文件内置 | 直接解密，自动提取专辑封面 |
| `.qmcflac` `.qmcogg` `.qmc0~8` `.tkm` `.bkc*` | QQ 音乐 v1 | 项目内置公开密钥表 | 传统 QMC 格式，无需任何密钥 |
| `.666c6163` `.6d7033` 等十六进制伪装名 | QQ 音乐 v1 | 同上 | 老版把扩展名改成魔数十六进制，已直接识别 |
| `.mflac` `.mgg*` `.mmp4`（QTag / PcV1Legacy 尾包） | QQ 音乐 v2 | 尾包内嵌 ekey | 完全离线解密，无需外部密钥 |
| `.mflac` `.mgg*`（STag / musicex 尾包） | QQ 音乐 v2 | 本机 QQ 音乐客户端自动取 ekey | 失败时可在卡片内粘贴 ekey 重试 |
| `.kwm` | 酷我音乐 | 从密文自身恢复密钥 | 剥离 1024 字节头后试出 32 字节循环异或钥匙 |
| `.kgma` | 酷狗 | 项目内置公共密钥表 | 无需账号 |
| `.kgg` | 酷狗 | 本机密钥库 KGMusicV3.db | 需本地酷狗客户端登录，且该曲目在客户端播放过一次 |

输出扩展名按解密后数据的魔数自动判定，例如 `fLaC` 输出 `.flac`，`RIFF` 输出 `.wav`。

## 快速开始

需要 Node.js 16 或更高版本。解密 `.kgg` 与自动获取 ekey 依赖 Windows，其余纯 JS 部分不限平台。

双击 `start.bat` 会自动检查 Node、启动服务并打开浏览器。也可以手动执行：

```bash
node server.js
```

浏览器访问 <http://localhost:8787>。换端口用 `PORT` 环境变量：

```bash
PORT=9000 node server.js          # bash
$env:PORT = 9000; node server.js  # PowerShell
```

## 网页端使用

1. 把文件或整个文件夹拖进页面，或点击选择，支持多选
2. 队列卡片逐首显示解密进度，完成后可直接试听或下载
3. 有内嵌封面的歌曲会在卡片黑胶与底部播放器里显示专辑封面
4. 解密完成两首以上时，标题栏出现「打包下载」，一键把全部产物打包 zip
5. ekey 自动获取失败时，卡片内会出现输入框，粘贴 ekey 后重试
6. 点「清除已完成」收起已完成的卡片

产物在服务端保留 2 小时后自动回收，需要留存请及时下载。

## 命令行使用

命令行仅支持 `.ncm` 与传统 `.mflac`，酷狗与新版 QQ 音乐格式请走网页端。

```bash
node cli.js <输入文件> [输出文件] [--ekey <QQ音乐ekey>]
```

`--ekey` 用于新版 QQ 音乐加密文件，省略时工具会尝试从本机客户端读取。

## 工作原理

- 解密是可逆的位运算还原，输出与源文件加密前的比特流一致，没有转码环节
- 服务端对产物做魔数校验，识别不出音频魔数时直接报错丢弃
- 打包下载用 store 模式 zip，音频本体已压缩，二次压缩无收益还费 CPU
- musicex 的 ekey 从本机客户端凭据获取，结果写入 `ekeycache.json` 避免重复读取
- 解密算法移植自 Rust，涉及浮点转整数的位置需复刻 Rust 的饱和转换语义，细节见 `HANDOFF.md`

## 常见问题

### 买的单曲是 WAV，为什么解出来是 FLAC

解密只还原字节，扩展名按内容魔数判定。平台在无损档位实际封装的是 FLAC 流，解出来自然带 `.flac` 扩展名。FLAC 属于无损编码，PCM 数据与你购买时的 WAV 完全一致。确需 WAV 可用 ffmpeg 转换，同样无损：

```bash
ffmpeg -i 歌曲名.flac 歌曲名.wav
```

### kgg 提示找不到密钥

kgg 的密钥存在本机酷狗客户端的数据库中。确认酷狗已登录，并且这首歌曲在本地客户端播放过至少一次。

### ekey 获取失败

保持 QQ 音乐客户端处于登录状态后重试。仍然失败时，把 ekey 粘贴进卡片内的输入框手动解密。

### 酷我 kwm 需要提供密钥吗

不需要。kwm 的密钥藏在密文自身的明文特征里，绝大多数文件直接解密。极少数识别异常时会按 mp3 输出，建议人工核对。

### 上传后提示文件过大

单文件上限 512MB。192kHz Hi-Res 的 flac 通常在 200MB 以内，超限一般是拖错了文件。

### 端口被占用

用 `PORT` 环境变量换一个端口，见快速开始一节。

## 隐私与合规

所有文件只在本机内存与磁盘中流转，工具不向任何服务器上传音乐数据。本项目仅供个人对已购音乐做格式研究，请勿用于分发受版权保护的内容。
